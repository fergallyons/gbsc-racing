What RaceOps is

One app for the whole race night

Race officer

Set the course, run the start, record finishes, publish results.

Skipper

Enter the race, manage crew and fees, file a protest.

Crew & public

Course, start clock, weather and results — no login needed.

Any phone or browser

Installs to the home screen — no app store

Keeps working with no signal

Three roles. The race officer uses a club PIN; each skipper has a boat PIN; crew and the public just open the link — race information is open, like the noticeboard. It runs in a browser, installs to the home screen like an app, and the parts that matter on the water keep working when the signal drops at the committee boat.
