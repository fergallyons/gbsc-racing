Easy to config per club. 
One platform.

Each club keeps its own branding, its own separate data and its own choice of features — and every club gets each improvement.

It is not a one-club project. Galway Bay, Royal Cork and Howth are all running on it, each in their own colours, with their own database and settings — Royal Cork bills fees per series, Galway per race, for example. When one club asks for something, all three benefit.
